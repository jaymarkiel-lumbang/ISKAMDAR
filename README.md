# ISKAMDAR
Thesis Project — Philippine scam-detection web prototype.

---

## Requirements

- **Python 3.10+** (the `py` launcher must be available — it comes with the standard Windows installer)
- A modern browser (Chrome, Edge, Firefox)

---

## Running locally

You need **two terminals** open at the same time — one for the web server, one for the scan backend.

### 1. Install Python dependencies

Open a terminal in the project root and run:

```
py -m pip install -r requirements.txt
```

### 2. Start the scan server (Terminal 1)

```
py backend/scan_server.py
```

You should see:
```
ISKAMDAR scan server running on http://localhost:5000
```

> Alternatively, double-click `backend/start_scan_server.bat` — it installs dependencies and starts the server automatically.

### 3. Start the web server (Terminal 2)

```
py -m http.server 3000 --directory WEB
```

### 4. Open the app

Go to **http://localhost:3000** in your browser.

---

## How it works

| Layer | What it does |
|---|---|
| `WEB/` | Static HTML/CSS/JS front end (Bootstrap 5 + custom styles) |
| `WEB/textmodel.js` | In-browser ML model (TF-IDF + logistic regression) trained on scam/legit text |
| `backend/scan_server.py` | Flask server that fetches the real page behind a URL and runs heuristic signal detection |

When you paste a link or message and click **Check Now**, the app:
1. Runs the in-browser text model on the input
2. Calls the scan server to fetch and analyze the actual page content
3. Combines both scores into a final risk level (Low / Medium / High)

## Project structure

```
ISKAMDAR/
├── WEB/
│   ├── index.html          # Home / check page
│   ├── result.html         # Scan result page
│   ├── report.html         # Report a scam page
│   ├── about.html          # About the project
│   ├── trends.html         # Trends page
│   ├── script.js           # All app logic
│   ├── style.css           # All styles
│   └── textmodel.js        # Trained ML model (generated by train_text.py)
├── backend/
│   ├── scan_server.py      # Flask page-scan API (port 5000)
│   ├── start_scan_server.bat  # Windows launcher for scan server
│   ├── train_text.py       # Trains the text model and outputs textmodel.js
│   └── ...                 # Other training/data scripts
└── requirements.txt
```

---

## Retraining the text model

If you update the training data, regenerate `textmodel.js` by running:

```
py backend/train_text.py
```

Then copy the output `textmodel.js` into `WEB/`.
