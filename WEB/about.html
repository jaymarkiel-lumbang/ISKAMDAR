How ISKAMDAR works

08 steps, one risk score

  1. 01

    Input

    The user shares a link or pastes an SMS text into the web app.

  2. 02

    Routing

    The system determines whether the input is a link, a message, or both, and routes it accordingly.

  3. 03

    Text analysis

    Message text is scanned for scam language patterns — urgency phrasing, unrealistic pay claims, and more.

  4. 04

    Fetching

    For a link, the system loads the real page in the background.

  5. 05

    Structural check

    The page's design and layout are scanned for known scam patterns.

  6. 06

    Behavior check

    Sign-up prompts, payment requests and redirects are checked as the page runs.

  7. 07

    Scoring

    Each warning sign adds points to one risk score, from 0 to 100.

  8. 08

    Result & decision

    The score and plain-language findings are shown, with a link to report the scam to official channels.
