              Method and limits

              What to keep in mind when reading the results

              Anonymous by design

              Only metadata is logged: input type, outcome, scores and warning signs. No message text and no URLs.

              Simulated data

              The scan log is generated for this project. Model metrics are computed on a labeled test set that is also simulated, so they show how the method behaves, not how it performs on real scams.

              Same scoring as the prototype

              Warning-sign weights combine, scores run 0 to 100, and levels are Low 0-29, Suspicious 30-69, High 70-100.
